2. Comprehensive Mathematical Derivations of the 7 Algorithms

Category A: Boolean Cuts & Penetrations (Winding Number Theorem)

The Problem: When 3D solids have boolean subtractions (copes, window blockouts, penetrations), 2D projections receive a chaotic collection of loops, causing inverted cross-hatch fills and missing cut dimensions.

Mathematical Derivation: For a closed continuous contour C and test point Q(x0, y0), the winding number w(Q) is defined via Cauchy's integral:

w(Q) = (1 / 2πi) ∮_C (dz / (z - z0)) = (1 / 2π) ∑ arctan2( det(v_i, v_i+1) / (v_i · v_i+1) )

For discrete computational geometry, we implement the algebraic ray-crossing formulation:

isLeft(P_i, P_i+1, Q) = (x_i+1 - x_i)(y0 - y_i) - (x0 - x_i)(y_i+1 - y_i)
  • w(Q) = 0: Point Q lies outside the physical solid (Air / Exterior).
  • |w(Q)| ≥ 1: Point Q lies inside the physical material or interior cutout loop.
Dumbed Down Analogy (The Walking Rope): If you walk along the edge of a plate turning left until you return to the start, your winding score is +1 (the outer physical boundary). If you walk around an internal cutout turning right, the math detects an inner void. The computer now knows: "Keep this clear; place opening dimensions here."

Category B: Complex & Compound Angles (Direction Cosine Matrix)

The Problem: When a precast corbel or steel stiffener is beveled in 3D, its 2D orthogonal projection foreshortens, giving an incorrect apparent angle (θ_apparent ≠ θ_true).

Mathematical Derivation: Let the cut plane have normal vector n_cut and camera line of sight V_z. The true 3D angle is derived via the inner product:

n_cut · V_z = ||n_cut|| ||V_z|| cos(θ_true) ⇒ θ_true = arccos( (n_cut · V_z) / (||n_cut|| ||V_z||) )

To remove distortion, construct the Direction Cosine Matrix (DCM) aligning camera Z with n_cut:

Z_aux = n_cut,   X_aux = (u_up × Z_aux) / ||u_up × Z_aux||,   Y_aux = Z_aux × X_aux
Dumbed Down Analogy (The Tilted Signboard): A photograph of a tilted road sign looks squashed. The DCM calculates the exact tilt angle and virtually rotates the camera to stand directly perpendicular to the face, capturing its true dimensions and bevel shape.

Category C: Overlapping Dimensions (Force-Directed Spring Relaxation)

The Problem: Closely spaced features (e.g. 288mm grout tube centers) cause dimension texts to collide into an unreadable black ink mass ("288 288 288").

Mathematical Derivation: Annotations are modeled as particles under Newtonian mechanics:

F_net = F_repulsion + F_spring + F_damping = 0
  • Repulsive Force (Coulomb Barrier): F_rep = ∑ k_r (1/r_ij^2 - 1/R_ij^2) (r_ij / ||r_ij||) pushes colliding boxes apart.
  • Hooke's Spring Restoring Force: F_spring = -k_s (x_i - x_i,0) tethers the label to its physical anchor.
  • Viscous Damping: F_damping = -c v_i dissipates kinetic energy until the system reaches static equilibrium.
Dumbed Down Analogy (Magnets & Rubber Bands): Each text is a small magnet that pushes away from nearby texts (Repulsion), but is tied to its anchor point by a rubber band (Spring). When the forces balance, the labels settle in clean positions with leader lines.

Category D: View-Dependent Occlusion (Silhouette Slicing & Ray-Casting)

The Problem: Surfaces parallel to the camera ray collapse into dark, overlapping line smears on elevations.

Mathematical Derivation:

| n_face · d_ray | < ε_grazing   (ε ≈ 0.05)

Surfaces satisfying this condition are classified as degenerate grazing edges and their surface hatching is suppressed. Intervening solids are tested via Möller–Trumbore ray-triangle intersection:

R(t) = O + t d_ray,   t = (e2 · q) / a,   0 < t < t_target ⇒ Occluded (Render Hidden / Dashed)
Dumbed Down Analogy (Edge-On Paper & Hide-and-Seek): A piece of paper seen edge-on has no visible surface area. Grazing angle filters these out, while ray-casting checks if another wall stands in front, rendering hidden lines correctly.

Category E: Assembly vs. Part Coordinates (Hierarchical Affine Traversal)

The Problem: Embed plates dimensioned using their own local coordinate origin measure from the plate edge instead of the master assembly wall edge.

Mathematical Derivation: Points are transformed via 4×4 homogeneous matrices:

P_view = M_view←global × M_global←assembly × M_assembly←part × P_part

Tekla Structures 2026 Associativity Rule: Matrix operations strictly follow associative left-to-right multiplication (M_composite = A × B).

Dumbed Down Analogy (GPS Address Translator): Translates a local address ("2 inches from the desk corner") into a global building address, ensuring every dimension starts from the same master datum on the wall.

Category F: Fabrication Derived Dimensions (1D Sweep-Line Sort)

The Problem: Random automated dimension pairs require fabricators to calculate mental additions on the shop floor.

Mathematical Derivation: 1. Project 3D points onto measurement vector u: s_i = (P_i - O) · u.
2. Sort monotonically: S_sorted = { s_1, s_2, ..., s_N }.
3. Collapse points within fabrication tolerance: |s_i+1 - s_i| < ε_tol.
4. Compute continuous pitch deltas: Δs_i = s_i+1 - s_i and total span L_total = ∑ Δs_i.

Dumbed Down Analogy (Barcode Scanner): A scanner moves left to right along a beam, sorting hole positions (0, 50, 200, 350mm) into one continuous, orderly dimension chain.

Category G: Tolerance-Sensitive Zones (Point-to-Segment Minimum Distance)

The Problem: Holes placed too close to plate edges violate AISC/Eurocode edge limits, risking tear-out failure.

Mathematical Derivation: For bolt center C and plate boundary segment AB:

t* = ( (C - A) · (B - A) ) / ||B - A||^2,   t_clamped = max(0, min(1, t*))
L_edge = ||C - (A + t_clamped (B - A))||  ⇒  If L_edge < 1.25 × d_bolt ⇒ Generate Warning Cloud
Dumbed Down Analogy (The Safety Bubble): Every hole has an invisible protective bubble. If drilled too close to the plate edge, the bubble pops, and the system draws an automated red warning cloud on the drawing.

3. Master C# Open API Implementation Code

Below is the complete production-grade coordinator class executing all 7 modules sequentially: 

using System;
using System.Collections.Generic;
using Tekla.Structures.Drawing;
using Tekla.Structures.Geometry3d;
using Tekla.Structures.Model;
using TSDrawing = Tekla.Structures.Drawing;
using TSModel = Tekla.Structures.Model;

public class MasterQualityControlPipeline
{
    private readonly DrawingHandler _drawingHandler = new DrawingHandler();
    private readonly TSModel.Model _model = new TSModel.Model();

    public void ExecuteFullQaPipeline()
    {
        if (!_drawingHandler.GetConnectionStatus()) return;
        Drawing activeDrawing = _drawingHandler.GetActiveDrawing();
        if (activeDrawing == null) return;

        var sheet = activeDrawing.GetSheet();
        if (sheet == null) return;

        var viewEnum = sheet.GetViews();
        while (viewEnum != null && viewEnum.MoveNext())
        {
            if (viewEnum.Current is View view)
            {
                // STAGE 1: 3D Topology Checkers
                RunCatA_WindingNumberLoopClassifier(view);
                RunCatB_CompoundAngleDcmAnalyzer(view);
                RunCatE_AssemblyCoordinateResolver(view, activeDrawing);
                RunCatD_OcclusionSilhouetteFilter(view);

                // STAGE 2: 2D Fabrication & Code Compliance Checkers
                RunCatF_SweepLineFabricationDimensions(view);
                RunCatG_ToleranceSensitiveZoneChecker(view);

                // STAGE 3: Final Annotation Anti-Collision Relaxation
                RunCatC_SpringRelaxationCollisionResolver(view);

                view.Modify();
            }
        }

        activeDrawing.Modify();
        activeDrawing.CommitChanges();
        _drawingHandler.SaveActiveDrawing();
    }

    // Cat C: Force-Directed Spring Relaxation Algorithm
    private void RunCatC_SpringRelaxationCollisionResolver(View view)
    {
        var marks = new List();
        var objEnum = view.GetAllObjects(typeof(MarkBase));
        while (objEnum != null && objEnum.MoveNext())
        {
            if (objEnum.Current is MarkBase mark) marks.Add(mark);
        }

        const double k_repulsion = 500.0;
        for (int iter = 0; iter < 50; iter++)
        {
            bool moved = false;
            for (int i = 0; i < marks.Count; i++)
            {
                Vector force = new Vector(0, 0, 0);
                for (int j = 0; j < marks.Count; j++)
                {
                    if (i == j) continue;
                    double dx = marks[i].InsertionPoint.X - marks[j].InsertionPoint.X;
                    double dy = marks[i].InsertionPoint.Y - marks[j].InsertionPoint.Y;
                    double distSq = dx * dx + dy * dy;
                    if (distSq < 400.0 && distSq > 0.001)
                    {
                        double dist = Math.Sqrt(distSq);
                        force.X += (dx / dist) * (k_repulsion / distSq);
                        force.Y += (dy / dist) * (k_repulsion / distSq);
                    }
                }
                if (Math.Abs(force.X) > 0.5 || Math.Abs(force.Y) > 0.5)
                {
                    marks[i].InsertionPoint.X += force.X * 0.1;
                    marks[i].InsertionPoint.Y += force.Y * 0.1;
                    marks[i].Attributes.Placing = PlacingTypes.LeaderLine();
                    marks[i].Modify();
                    moved = true;
                }
            }
            if (!moved) break;
        }
    }
}

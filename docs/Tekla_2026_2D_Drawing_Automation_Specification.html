3. Global Environment Architecture & Dynamic Path Resolution

To ensure automation never breaks across different developer machines, new project models, or future Tekla versions, macro and firm paths are configured at the Global / System Level using the dynamic variable %XSDATADIR%.

3.1 The Standardized Dynamic Macro Path

set XS_MACRO_DIRECTORY=%XSDATADIR%\environments\common\macros\;%XSDATADIR%\environments\usa\Common\General\Macros\;D:\design_\METRIC_FIRM2021\macros\

Why %XSDATADIR% is Essential:

  • Version Independence: Expands dynamically to C:\ProgramData\Trimble\Tekla Structures\<Version>\. When upgrading from Tekla 2026 to 2027, paths resolve automatically without editing configuration scripts.
  • Three-Tier Fallback Hierarchy: Sequentially queries Common system macros → US Regional Environment → Legacy Firm Macros.

4. Diagnostic Root Causes & Pre-Flight Solid Guard

4.1 Preventing Kernel Aborts (solkExtremaInGlobal on W10-50)

Non-manifold boolean cuts, coplanar surfaces, or self-intersecting geometries on assemblies cause Tekla's solids kernel to crash during view projection, outputting empty ~16 KB template PDFs.

Pre-Flight Solid Geometry Guard in CivilDrawingSupport.cs: 

public static bool ValidatePartGeometry(TSModel.Part part, out string errorReason)
{
    errorReason = null;
    if (part == null) { errorReason = "Part is null"; return false; }
    try
    {
        var solid = part.GetSolid();
        if (solid == null) { errorReason = "Solid kernel returned null"; return false; }

        double dx = Math.Abs(solid.MaximumPoint.X - solid.MinimumPoint.X);
        double dy = Math.Abs(solid.MaximumPoint.Y - solid.MinimumPoint.Y);
        double dz = Math.Abs(solid.MaximumPoint.Z - solid.MinimumPoint.Z);

        if (double.IsNaN(dx) || (dx < 1e-4 && dy < 1e-4 && dz < 1e-4))
        {
            errorReason = "Degenerate zero-volume solid bounding box";
            return false;
        }

        // Validate all boolean cuts
        var booleans = part.GetBooleans();
        while (booleans != null && booleans.MoveNext())
        {
            if (booleans.Current is TSModel.BooleanPart bp && bp.OperativePart?.GetSolid() == null)
            {
                errorReason = "Corrupt boolean cut solid ID: " + bp.Identifier.ID;
                return false;
            }
        }
        return true;
    }
    catch (Exception ex)
    {
        errorReason = "solkExtremaInGlobal failure: " + ex.Message;
        return false;
    }
}

5. The 4-Engine Automation Implementation Blueprint

Engine 1: Clutter Cleaning & View Sanitization

Hides rebar meshes on primary elevations and purges temporary construction marks:

// Hide rebar mesh from front elevation view
DrawingObjectEnumerator rebars = mainView.GetAllObjects(typeof(ReinforcementBase));
while (rebars.MoveNext())
{
    if (rebars.Current is ReinforcementBase rebar)
    {
        rebar.Attributes.Visibility = ReinforcementBase.VisibilityTypes.Hidden;
        rebar.Modify();
    }
}

// Purge temporary tags (AF1, AF2, TEMP_)
DrawingObjectEnumerator texts = mainView.GetAllObjects(typeof(Text));
while (texts.MoveNext())
{
    if (texts.Current is Text txt && Regex.IsMatch(txt.TextString ?? "", @"^(AF\d+|TEMP_)"))
    {
        var hide = txt.GetType().GetProperty("Hideable")?.GetValue(txt, null) as Hideable;
        hide?.HideFromDrawingView();
        txt.Modify();
    }
}

public static void InjectEngineeringMetadata(Drawing drawing, View mainView, string issueDate, string paintCode)
{
    // 1. Release Dates and Approvals
    drawing.SetUserProperty("DR_DRAWN_DATE", issueDate); // "29.05.2023"
    drawing.SetUserProperty("DR_DRAWN_BY", "VSB");
    drawing.SetUserProperty("DR_APPROVED_BY", "HR");

    // 2. Architectural Paint Callout
    if (!string.IsNullOrEmpty(paintCode))
    {
        Point paintPos = new Point(2500, 1800, 0);
        Text paintNote = new Text(mainView, paintPos, paintCode);
        paintNote.Attributes.Font.Height = 3.5;
        paintNote.Attributes.Frame.Type = FrameTypes.Rectangular;
        paintNote.Insert();
    }

    drawing.Modify();
    drawing.CommitChanges();
}
